# Character Counter App

## Description
Character Counter is a simple web application that counts characters and words in real time as the user types in the text box.

## Purpose
The purpose of this project is to practice HTML, CSS, and JavaScript, including event handling, DOM manipulation, and string methods.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Count characters in real time.
- Count words automatically.
- Include spaces in the character count.
- Simple and attractive user interface.
- Responsive design.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start typing in the text box to see the character and word counts.
